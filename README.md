# QuickBite - Distributed Food Ordering System

A distributed food ordering system built with Spring Boot and modern web technologies, featuring load balancing across multiple servers.

## Features

- 🔐 **Secure Authentication**: User registration and login system
- ⚖️ **Load Balancing**: Distributes orders across multiple servers
- 📊 **Admin Dashboard**: Real-time monitoring of server loads and orders
- 🔄 **Server Management**: Ability to reset and manage server loads
- 📱 **Responsive Design**: Modern UI that works across all devices
- 🌙 **Dark/Light Mode**: Supports both dark and light themes

## Architecture

The system consists of multiple components:

- **User Service**: Handles user authentication and management
- **Server 1 & 2**: Distributed servers for processing orders
- **Admin Service**: Manages and monitors the system
- **Frontend**: Modern web interface built with HTML, CSS, and JavaScript

## Tech Stack

### Backend
- Java Spring Boot
- Spring Security
- JPA/Hibernate
- MySQL Database

### Frontend
- HTML5
- CSS3 (with Tailwind CSS)
- JavaScript
- Font Awesome Icons

## Getting Started

### Prerequisites
